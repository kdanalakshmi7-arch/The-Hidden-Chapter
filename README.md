# The Hidden Chapter ✨📖

**The Hidden Chapter** is an enchanting, fantasy-inspired personal journaling web application that transforms everyday writing into an immersive journey through a magical library. Designed as a private space for self-expression, creativity, and preserving memories, it combines the comfort of a traditional journal with the charm of an interactive digital scrapbook.

Explore a beautifully themed library, write personal chapters, decorate scrapbook pages, revisit meaningful moments through a memory calendar, and leave letters for your future self with time capsules. The Reflection Garden offers a gentle space for gratitude, moods, and personal reflections, while the Curiosity Shop brings together creative templates, stickers, and atmospheric themes.

### ✨ Key Features

- **Magical Library:** An immersive home screen with an enchanting visual atmosphere.
- **Personal Journal:** Create, edit, organize, and favorite journal entries.
- **Scrapbook Studio:** Express yourself through decorative elements, stickers, and creative page layouts.
- **Memory Observatory:** Explore journal entries through a calendar and chronological timeline.
- **Time Capsules:** Write messages for your future self.
- **Reflection Garden:** Record moods, gratitude, intentions, and personal thoughts.
- **Curiosity Shop:** Discover writing templates, creative prompts, stickers, and themes.
- **Personalized Themes:** Choose between Magical Academia, Coquette, Celestial, and Cottagecore aesthetics.
- **Privacy-Focused Storage:** Keep journal data in your browser, with JSON backup and restore functionality.
- **Personal Settings:** Customize the writing experience, animation preferences, accessibility options, and autosave settings.

### 🛠️ Built With

HTML · CSS · JavaScript · Browser Local Storage

### 🎯 Project Vision

The Hidden Chapter aims to make journaling feel less like a daily task and more like opening a secret book filled with memories, thoughts, dreams, and discoveries. It brings together personal reflection, creative freedom, and immersive design in one thoughtfully crafted web experience.

**Every thought has a place. Every memory has a chapter. And every chapter belongs to you.**
